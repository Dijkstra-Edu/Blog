## 📌 About the Project

The **Dijkstra Blog** is a standalone, public-facing blogging platform built for students and developers to share their technical learnings, problem-solving journeys, and project experiences.

It is **separate from the main Dijkstra dashboard and platform**, and is designed specifically for:
- Publishing technical blogs (DSA, CS fundamentals, engineering topics)
- Writing LeetCode-style explanations and learning notes
- Sharing personal technical journeys and project write-ups
- Making individual contributions visible to the wider developer community

The blog serves as a bridge between **individual effort** and **public proof of work**, allowing readers to understand what a contributor has learned, built, or explored.

---

## 🎯 Purpose & Vision

The core idea behind the Dijkstra Blog is simple:

- Give students a **credible public space** to document their work
- Encourage **writing as a learning tool**
- Help contributors build a **technical footprint** beyond private notes or local files
- Make learning outcomes visible to recruiters, peers, and the community

Every article published reflects the work and growth of a real individual.

---

## ✨ What You’ll Find on the Blog

- 🧠 **DSA & Problem-Solving Articles**  
  Clear explanations of algorithms, patterns, and approaches — similar to LeetCode or interview-style blogs.

- ✍️ **Personal Technical Blogs**  
  Write-ups on learnings, mistakes, and insights gained during projects, internships, or self-study.

- 🏗️ **Project & System Write-ups**  
  Articles explaining how a project was built, design decisions taken, and challenges faced.

- 🌍 **Community Contributions**  
  Content written by different members of the Dijkstra community, each with their own voice and focus.

---

## 🛠️ Tech Stack

- **Framework**: Astro  
- **Languages**: TypeScript, JavaScript  
- **Content Format**: Markdown-based blogs  
- **Styling**: CSS  
- **Deployment**: Hosted at  
  👉 https://blog.dijkstra.org.in

> The blog is built using **Astro**, with a component-based structure inspired by modern **React ecosystems**.

The focus of this repository is **content delivery, readability, and simplicity**, rather than complex backend logic.

## 🚀 Getting Started (Local Setup)

### 1. Clone the Repository

```bash
git clone https://github.com/Dijkstra-Edu/Blog.git
cd Blog
2. Install Dependencies
npm install
# or
yarn install
3. Run the Development Server
npm run dev
# or
yarn dev
Open http://localhost:3000 in your browser to view the blog locally.
```

## 🧩 Writing & Publishing a Blog
Create a new Markdown file in the appropriate content directory.

Follow the existing structure:

- Clear title

- Short introduction

- Well-defined sections

- Practical examples where possible

- A short conclusion or takeaway

Keep the writing honest, simple, and technical.

Note: Open a Pull Request with a brief description of your article.
